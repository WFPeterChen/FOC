# FOC 项目完整归档

本仓库归档 FalconFOC 电机驱动开发目录，包括源码、硬件、模型、文档、视频、上位机、构建产物、标定备份和参考项目。归档不表示所有历史版本均适用于当前电机。

## 目录

- `FalconFoc-main/`：FalconFOC硬件与STM32G431固件，上位机和相关资料。
- `backups/`：历史固件、参数、标定页及刷写前完整Flash备份。
- `moteus-main/`、`moteus_blog/`：保留的参考代码与文章；原有版权和许可证保留。
- `.claude/`：原目录工具配置与示波器技能，原样归档。`settings.local.json` 含本机权限设置，迁移时应自行审阅。
- `UPLOAD_MANIFEST.json`：归档前逐文件SHA-256、大小、权限和空目录清单。

## 当前固件

当前适配LJW8115 KV76（21极对），为原FalconFOC板的24V/4A初次调试配置，不是48V/12A验证版本。首次无有效标定启动时会自动标定并带动转子。详细配置及实机验证限制见 `FalconFoc-main/2.Firmware/FalconFoc/LJW8115_KV76_BRINGUP.md`。

2026-11-15会话中已通过J-Link写入并校验固件；后将启动选项从0xFFEFF8AA改为0xFBEFF8AA（nSWBOOT0=0、nBOOT0=1）。当次未触发选项重载，也尚未确认断电重启后的电机运行结果。

构建：

```sh
cd FalconFoc-main/2.Firmware/FalconFoc/gcc
make all -j4
```

烧录前必须确认板型、电源、电机和编码器配置，并保留原板Flash备份。历史5210/4010标定不可作为新电机标定使用。
