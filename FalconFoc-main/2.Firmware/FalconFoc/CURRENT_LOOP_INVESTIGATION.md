# #5 统一电流环 —— 调查记录 (2026-06-29)

> 目标: 把运行时电流环从"裸 PID(PID_Calc)+commonInverseFOC"(称 **A 路**) 换成标定时用的
> ODrive 式 `FOC_current`(称 **B 路**, 带 vbus 归一 / 积分泄放抗饱和 / 相位超前)。
> 结论先说: **B 路可复现地比 A 路差 ~1.6×(齿槽纹波抑制), 且所有可检查的控制数学都已验证等价 —— 不采用 B, 转而在 A 路上加前馈。**
> 这份记录的价值在**方法论**和**排除过程**, 给以后类似问题做模板。

## 0. 调查方法 (可复用模板)
挂一个 **A/B 在线开关** `g_dbg_unified_iloop`(默认0=A, SWD置1=B), 默认不改行为、可随时切回。
再加一组**诊断旋钮**(SWD 可调, 不重烧就能换实验): `g_dbg_padv`(相位超前缩放)、`g_dbg_vlog_sel`
(g_vlog 记 转速/i_q/iq_set/跟踪误差/i_d 之一, 5kHz)、`g_iloop_cyc`(电流环分支 DWT 耗时)。
然后**逐个变量隔离测量**。调试器: **J-Link**(ST-Link 那条 SWD 线坏了)。

## 1. 逐项排除 (全部实测)
| 怀疑项 | 方法 | 结果 |
|---|---|---|
| 调制标度 svm() vs Svpwm_Sector | Python 逐位复刻同输入比对 | **逐位相同**(B/A=1.000) |
| 相位超前 | `g_dbg_padv=0` 关掉再测 | 关了仍差 → **排除** |
| sin/cos 精度 | 查 arm_dsp_shim.c | `arm_sin_f32` 就是 `fast_sincos`, **两路共用** |
| Clarke/Park/逆变换 | 读码比对 | 与 A 一致且与 inverse_park 自洽 |
| 电流环增益 P/I | **活体读** foc->current_ctrl_p/i_gain | p=0.377、i=411(=Controller.i_gain/Ts), **与 A 一致** |
| 积分双 Ts bug | 发现 FOC_current `integral+=err·i_gain·Ts` 而 i_gain 已含 Ts | **真 bug, 已修**(unified分支预除Ts); 但修了纹波不变 |
| d 轴泄漏 | g_vlog 记 i_d | B 的 i_d **更干净**(std0.09 vs A0.30), 排除 |
| 抗饱和(钳/泄放) | 工作点分析 | 10turn/s 轻载 mod≈0.16≪0.779, **两路都没触发** |
| 执行耗时 | DWT 测 g_iloop_cyc | A=3.68µs, B=7.11µs(2×, 但都≪50µs周期; 多出3.4µs仅占6.8%, 不足以恶化10-40Hz低频抑制) |

## 2. 关键方法论教训 ⚠️
最初测得"B 差 4×"(CV 8%→31%)。后来做**重复性测试**(同一次起转、稳态后连抓3次, 不重新spinup):
- A: std 0.95 / 0.80 / 0.77
- B: std 1.23 / 1.38 / 1.47

真实差距是 **~1.6×**(A≈0.84, B≈1.36), 不是 4×。**早期"4×"被夸大了**, 因为我**分别起转**比较单次——
齿槽速度纹波在 1 圈窗口内随**转子起始位置/起转暂态**波动很大。
**教训: 比较两个配置前, 先测同配置的 run-to-run 重复性/离散度; 别信单次对比。** 起转暂态和转子位置会污染单窗口统计。

## 3. 现象与残留谜团
- A、B 在**相同频率**(10/20/29/39Hz = 机械1/rev及谐波 = 齿槽/偏心扰动)抖, B 幅值约 1.6×。
  即 B **不是产生新纹波**, 而是对**同一齿槽扰动的抑制差 1.6×**。
- 低频(10-40Hz)抑制由环路增益决定, 但 P/I 增益已验证与 A 相同; 执行延迟只多 6.8% 拍, 不影响低频。
- **结论: 用 SWD 能查的控制数学全等价, 残留 1.6× 无法用固件层差异解释。** 要进一步定位需**示波器看实际相电流/相电压波形**
  (看 B 的电流波形是否有 A 没有的畸变), SWD 层到此为止。

## 4. 工程决策
- **不采用 B(整体换 FOC_current)**: 可复现地差 1.6%、原因未明 —— 不上线没吃透又更差的路径。
- **#5 转向**: A 路已经是更好的那条, 且已有 vbus 实时补偿(#3)。真正缺、真正值钱的是 ODrive 电流环比我们多的
  **bEMF 前馈 + ω·L 解耦前馈**(见 foc.txt / [[foc-opensource-references]]), 很可能才是高速改善点。
  → 下一步: 在**A 路**上加这两个前馈项(挂开关 A/B 验证高速纹波是否下降), 不动证明好用的环结构。
- A/B 脚手架 + 诊断旋钮**保留在固件里**备查(默认全关=A 路原行为)。正式部署前再清理这些诊断代码。

## 5. 再试统一电流环 (2026-07-04) —— 修公平后重测

重新加回 A/B 在线开关 `g_dbg_unified_iloop`(0=A默认/1=B FOC_current)。**关键: 上次"B差1.6×"是不公平对比**,
这次修了 B 路(FOC_current)三个真缺陷后再比:
1. **双 Ts 积分 bug**: `i_gain` 已含 Ts(FOC_update_current_gain), FOC_current 里又乘一次 Ts → 积分几乎失效。已改为不再乘。
2. **缺死区补偿**: 死区补偿是 2026-06-30 加的(在 #5 调查之后), A 路有、FOC_current 没有 → 补上 `Deadtime_Compensate`。
3. **缺 bEMF/ωL 前馈**: A 路有、B 没有 → 给 FOC_current 加 vd_ff/vq_ff 入参, 与 A 同源。
4. **致命: foc 增益从没同步过(=0)**。`FOC_update_current_gain` 只设了 `Controller.*` 和 `IqPID/IdPID`, **没设 `foc->current_ctrl_p/i_gain`**;
   而 `FOC_reset`(每次 GUARD/IDLE)又把它清零。→ B 路电流环 P/I=0, 只剩前馈, 位置直接飘走(实测 cmd0.5→got5.2)。
   修法: **在 B 分支每拍从 Controller 同步** foc 增益(覆盖 FOC_reset 清零)。修完 B 位置保持 err=0.001, 功能正常。
   ⚠️ 若不查这个, B 会因"零增益"被误判成烂 —— 正是这类隐藏 confound 让上次结论不可信。

**公平对比结果(warm, 每档多次取均值, 速度环 sweep 的速度跟踪 std rad/s, 越低越好):**

| 速度 | A(默认) | B | B/A |
|---|---|---|---|
| 5  | 0.63 | 0.66 | 1.05 平 |
| 10 | 1.22 | 1.15 | 0.94 B略好 |
| 20 | 1.89 | 2.18 | 1.15 |
| 30 | 2.37 | 2.99 | 1.26 |
| 40 | 2.30 | 3.54 | **1.54** |

**结论(初测)**: 修公平后, **低速 A≈B(B 甚至略好), 但 B 随速度单调变差, 40rad/s 时差 ~1.3~1.5×**。

**假说验证(2026-07-04, 加 SWD 旋钮 g_padv_k/g_padv_filt 直接实验)**: 原以为是"相位超前×齿槽噪声"。
加旋钮把**相位超前完全关掉(g_padv_k=0)**后测: 40rad/s std=2.87/3.02/2.97≈**2.95, 与开着(≈3.0)几乎一样**, 仍远高于 A(≈2.3)。
→ **假说被推翻: 相位超前不是高速劣化的原因。** 诚实记录: 我猜错了。
残留差异只剩 B 独有的**积分泄放抗饱和**(vs A 的 PID 钳位) 与 **svm() 边界**(调查称与 Svpwm_Sector 位同, 但未上示波器验高速相电流)。
另外 **B 起转鲁棒性差**: sweep 起始低速段约 1/3 概率堵转(got≈0), A 无此问题。

**工程决策(更坚定): 默认走 A。** B 已修成功能正确、可公平对比, 但**无收益且有起转鲁棒性问题**, 高速劣化根因未明(要示波器看相电流,
即原调查第3节的结论——SWD 层到此为止)。B 挂开关备查, 换低齿槽电机时再评估。
**本次真正价值**: 推翻了旧"1.6×均匀变差"(那是零增益/缺死区/缺FF 的不公平假象), 也推翻了我自己的相位超前假说 —— 现在结论建立在公平对比上。
