## 2. 硬件层 —— 影响标定准确性的因素

- **电流采样链**（最关键）：分流电阻 1mΩ 容差、运放增益 50 容差/失调、ADC 基准 3.3V 精度、
  ADC 非线性(DNL/INL)、**采样时刻必须与 PWM 中点同步**（避开开关噪声）、采样带宽。
  → 电流测不准，Rs/Ls/Kt/力矩 全部带误差。
- **死区(dead-time)**：FD6288Q 栅驱死区使"**实际施加电压 ≠ 指令电压**"，
  在低压/低速时占比大 → 直接污染 Rs/Ls/Kt 测量与低速力矩线性度。**是否做死区补偿？**（现固件大概率没有）
- **MOSFET Rds_on**：串进相回路，标 Rs 时被算进去：`Rs_meas = Rs_real + 2·Rds_on + 走线阻 + 死区等效阻`。
- **母线电压采样**：分压(R40/R42)容差；调制是否实时用测量 vbus（而非常数 BATVEL）。
- **编码器 MT6816**：14bit 分辨率、积分非线性、**安装偏心 / 磁铁对中**、读数延迟（SPI+滤波）。
- **温度**：铜阻 +0.39%/°C；NdFeB 磁链 -0.1%/°C。标定时记录温度。

---

## 3. 软件层 —— 影响标定准确性的因素

- **ADC 采样与 PWM 同步**（中点采样，注入转换触发）。
- **死区补偿算法**（有无、是否按电流符号补偿）。
- **SVPWM/调制线性度**、过调制区行为。
- **Clarke/Park 变换正确性、角度延迟补偿**（高速时 θ 延迟→力矩偏差）。
- **标定算法本身**：
  - Rs：DC 注入测 V/I（注入电流大小、含死区/失调的常数项误差）。
  - Ls：电流阶跃 / 高频注入（注入幅值影响**磁饱和**→ Ld/Lq）。
  - 编码器零位/方向/极对数检测的鲁棒性。
- **编码器线性化 LUT(`offset_lut`) / cogging map**：当前 `PRE_CALIBRATED=1` **跳过了** → 残留纹波(~17%)。
- **速度/位置估计滤波**：延迟与噪声的权衡。

---

## 4. 标定方法层 —— 逐项怎么测准

1. **Rs**：多电流点测 V/I 取**斜率**（斜率消掉死区/失调的常数项）；记录温度 → Rs(T)。
2. **Ls(Ld/Lq)**：高频小信号注入；多电流点看饱和；SPM 电机 Ld≈Lq，航模可能微凸极。
3. **Kt / Ke**：**反电动势法**（外部匀速拖动，测开路相电压的频率与幅值）或测力计直接测力矩；
   与 Rs/Ls 解耦。Kt 和 Ke 应一致（同一物理量），互相校验。
4. **cogging**：极慢匀速旋转，记录"维持匀速所需电流(=力矩)随机械角"的周期分量 → cogging map（按角度补偿）。
5. **摩擦**：多个匀速点的稳态电流 → 拟合 `τ_f = τ_coulomb·sign(ω) + b·ω`（库仑+粘滞分离）。
6. **惯量 J**：给力矩阶跃测角加速度 `J=τ/α`；或自由减速法。
7. **温度模型**：升温到不同温度重测 Rs、Kt，建线性漂移。

---

## 5. 通信/控制层 —— 也会进 sim2real gap（别忽略）

- **DM 协议量化**：力矩 12bit/±0.3N·m、位置 16bit/±50rad、速度 12bit/±300rad·s⁻¹
  → 指令与反馈都有**量化误差**，仿真要把这个量化建进去。
- **控制延迟**：CAN 1Mbps 传输 + 20kHz 电流环 + 反馈周期 → 端到端时延，RL 对延迟敏感。
- **限幅与保护**：电流/转速/温度限幅、欠压/过流的离散行为。

---

## 6. 建议攻克顺序（资源到位后逐个做）

1. **Kt 实测**（反电动势法）—— 力矩准确度第一位，RL 力矩映射的根基。
2. **cogging map 标定** —— 解决起转/纹波，对 RL 接触力建模重要（航模电机尤其）。
3. **摩擦标定**（库仑+粘滞）。
4. **Rs/Ls 多点精标 + 死区补偿**（先在固件加死区补偿，再重标）。
5. **惯量 J**。
6. **温度漂移模型**。
7. **把通信量化 + 延迟建进仿真**。

> 每攻克一项：固件侧加测量/补偿 → 实测得参数 → 写进仿真模型 → 对比 sim/real 响应闭环验证。

### 6.1 现在就能做（不需扭矩传感器，用现有 bench：板+电机+SocketCAN+SWD+限流电源）
- **Kt（经 Ke 反电动势法）**：外部匀速拖动电机，测开路相电压 vs 转速 → Ke；SI 下 **Kt=Ke**。
  扭矩传感器只是后面的**独立交叉验证**，不必等它才有 Kt。
- **编码器线性化 LUT**：跑一次完整标定(PRE_CALIBRATED=0 含 offset_lut)，消大部分纹波。
- **cogging map**：极慢匀速旋转，记录 iq 随机械角的周期分量（iq 即力矩代理，待 Kt 定后换算 N·m）。
- **摩擦（库仑+粘滞）**：多转速稳态 iq → 拟合 `iq_f = a·sign(ω)+b·ω`（×Kt 得力矩）。
- **Rs/Ls 多点精标 + 死区补偿**：纯电气、电流为基，先在固件加死区补偿再重标。
- **惯量 J（近似）**：自由减速法（配合已标摩擦）或 iq×Kt_估 做力矩阶跃。
- **通信量化 + 延迟**：纯分析，直接建进仿真。

### 6.2 等扭矩传感器（"最后一公里"，直接物理力矩）
- Kt 的**绝对标定与交叉验证**（对照 Ke 法）。
- **力矩纹波/cogging 的物理 N·m 量级**（而非 iq 代理）。
- 摩擦力矩、堵转力矩的**绝对值**校准。

**建议现在的起步项**：① 跑完整标定拿 LUT（顺手消纹波）→ ② Ke 反电动势法测 Kt → ③ cogging map。
